# 定期テスト

**作成中です(まだ使えません)。** 下は、これから作るアプリの説明です。

年に数回(3〜5回)の定期テストについて、教務の仕事をまとめて行うアプリです。

## できるようにすること

- テスト時間割を作る(日程・時間ごとに、学年ごとの教科を割り振る)
- 試験監督を割り当てる
- 各クラスに掲示する時程表と、別室(時間延長の生徒)の時程表を作る
- 生徒の名簿を Excel・CSV から貼り付けて入れる
- 点数を入れる(各教科の先生がアプリに直接入力、または Excel から貼り付け)
- 平均点・得点分布、合計と順位を出す
- 生徒ごとの個票(素点をまとめた用紙)と、学年の成績一覧表を出す
- 印刷して配布・掲示する。Excel に書き出す

## データの保存場所

- データファイル(`.json`)を校務共有サーバーに置いて、複数の先生で使う予定です。
- **生徒の名前・点数は、校内の共有サーバーでだけ扱います。** インターネットやクラウドには置きません。
