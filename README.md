# 定期テスト

**試しに使ってみる段階です。** 点数の入力・集計はまだできません(次の段階で作ります)。

年に数回(3〜5回)の定期テストについて、教務の仕事をまとめて行うアプリです。

## できること

- テストの回(例：2学期中間)ごとに、日程・時程・教科ごとのテスト時間を決め、時間割を作る(教科は全学年共通)
- 監督表を作る前に、先生方の休暇・出張を集める用紙を印刷し、集めた結果を入れる
- 試験監督を自動で割り当てて、手で直す(教員とサポーター。サポーターは主に別室)
- 欠席・別室受験・時間延長などの、配慮の必要な生徒を入れる
- 次の用紙を印刷する

| 用紙 | 大きさ | 使い方 |
|---|---|---|
| 休暇集約用紙 | A4 | 監督表を作る前に、先生方に書いてもらう |
| 監督表 | A4 1枚(A3も可) | 縦に先生、横に教科(テストの時間と時刻)。その時間に入る教室(1-1 など)を書く。別室の延長の時刻と、別室・延長の生徒の表も付く |
| 時程表(通常の教室) | A3・1日1枚 | 各教室に掲示する(クラス名を入れてクラスごとにも出せる)。大きな文字 |
| 時程表(別室) | A3・1日1枚 | 別室に掲示する。時間延長の終わりの時刻も載る |
| 配慮生徒一覧 | A3(A4も可) | 当日、職員室に掲示して、受験状態を書き込む |
| 注意事項 | A3 1枚 | 教室に掲示して、生徒に知らせる |
| 出欠記録用紙 | A3 1枚(全日)か A4・1日1枚 | 当日、学級の在籍・出欠を手書きで記録する |

(このあと作るもの：点数の入力、平均点・得点分布・合計と順位、生徒ごとの個票、学年の成績一覧表、Excel への書き出し)

## はじめに(置き場所)

1. このアプリのフォルダ(`index.html` と `css`・`js` のフォルダ)を、**まとめて**校務共有サーバーに置きます。
2. `index.html` を **Chrome か Edge** で開きます(ダブルクリックで開かないときは、右クリック →「プログラムから開く」)。
3. 年度のはじめに1回だけ「新規作成」を押して、データファイル(1年分・全学年で1つ)を、同じフォルダに保存します。
4. 次からは、開くと前回のファイルが出ます(「前回のファイルを開く」を1回押します)。

どんなアプリか試すだけなら、はじめの画面の「見本を表示する」を押してください(架空の学校・名前です。保存されません)。

## 使い方

画面の上の「✏ 編集する」を押すと入力できます。**編集できるのは1度に1人**で、ほかの先生には「◯◯先生が編集中」と出ます。終わったら「編集を終える」を押してください。入力した内容は自動で保存されます。

### 年に1回

1. **設定**：学年・クラスの数、別室(相談室など)、教科、先生・サポーターを入れます。先生の「担当教科」は、その教科のテストの時間に監督から外すために使います。管理職など監督に入らない人は「監督なし」に印を付けます。
2. **名簿**：校務支援システムなどから出した名簿を Excel で開き、「学年、組、番号、氏名」の列をコピーして貼り付けます。

### テストのたびに

1. **テストの回**：「新しい回を追加」(前の回をもとに作ることもできます)。テストの日を追加し、教科ごとに「実施」「テスト時間」「満点」を入れます。注意事項の文もここで直します。
2. **時間割**：日ごとに、テストの時間の始まりの時刻と教科を選びます(教科は全学年共通)。朝の学活、テストの間の学活、テストのあとの給食・帰りの学活なども「学活・給食などを追加」で入れておくと、時刻の順に並び、時程表に載ります。
   下の「別室の時程」で、別室だけテストの始まりをずらせます(空のままなら教室と同じ時刻)。抜けや、時間の重なり(延長が次の時間にかかるなど)があると上に出ます。
3. **休暇**：「休暇集約用紙を印刷」で用紙を配り、集まったらます目を押して入れます(押すたびに「休暇 → 出張 → その他 → 空」)。
4. **配慮生徒**：欠席の予定・別室で受ける・時間延長の生徒を入れます。延長は「倍率」(テスト時間 × 1.3倍など)か「分を足す」(テスト時間 + 10分など)を選べます。教科や本人の希望で時間を変えるときは「教科ごとの時間」で分を入れます。
5. **監督**：縦に先生、横にテストの時間が並んだ表です。「自動で案を作る」を押し、ます目で入る教室(1-1 など)を選んで直します。自動の案は、この回の回数をそろえたうえで、年間の回数が少ない人を優先します(下に「年間の監督回数」の表があります)。別室の監督は延長の終わりまで続けて見るので、次の時間の監督に間に合わない人は入れません。気になるところ(休暇の人が入っている、同じ時間に2か所など)は上に出ます。
6. **印刷**：用紙を選んで「画面で確かめる・印刷」。PDF にするときは、印刷の画面の送り先で「PDF に保存」を選びます。
7. テストのあと、配慮生徒一覧に書き込まれた受験状態を「配慮生徒」タブの下の表に入れておくと、追試の確認などに使えます。

## データの保存場所

- **データファイル(`定期テスト_2026年度.json` など)は、校務共有サーバーのアプリと同じフォルダ**に置きます。1年分・全学年で1つのファイルです。
- **生徒の名前が入るので、インターネットやクラウド(Google ドライブなど)には置かないでください。** 配慮生徒一覧などの印刷物も、取り扱いに気をつけてください。
- ブラウザには、生徒の名前などは残しません(開いたファイルの場所と、画面の見方の好みだけを覚えます)。

## バックアップと復元

- 「設定」タブの「データを書き出す(バックアップ)」で、日付の入ったファイル(`定期テスト_バックアップ_2026年度_2026-10-01.json` など)をダウンロードします。テストの前後など、ときどき書き出して、共有サーバーに控えておいてください。
- データファイルが壊れた・消えたときは、「編集する」を押してから「データを読み込む(復元)」で控えのファイルを選びます。

## 困ったとき

- **「◯◯先生が編集中」と出て編集できない**：その先生に「編集を終える」を押してもらってください。ブラウザを閉じ忘れている場合は、15分たつと表示が消えます。急ぐときは、そのまま「編集する」を押すと確認が出ます(同時に編集すると、どちらかの入力が消えるので注意)。
- **「このファイルは、あなたが開いたあとに…保存しています」と出た**：ほかの先生が保存しています。「キャンセル」を押し、入力した内容を控えてから、ページを開き直してください。
- **保存できない**：共有サーバーにつながっているか、フォルダに書き込む権限があるか確かめてください。
- **印刷がはみ出す・小さすぎる**：印刷の画面で「倍率」が「既定」、「余白」が「既定」になっているか確かめてください。A3 はプリンタが A3 に対応している必要があります。
- **ファイルを開けない・保存のボタンがない**：Chrome か Edge で開いているか確かめてください。
